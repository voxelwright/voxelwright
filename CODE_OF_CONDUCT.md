# Code of conduct

Participants in Voxelwright follow the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## Reporting

The maintainer, Pavlo Zahynailo ([@zahynailo](https://github.com/zahynailo) on GitHub), enforces this code in every project space: issues, pull requests, discussions and anything posted on the project's behalf.

To report behaviour privately, open **Security → Report a vulnerability** on the [repository](https://github.com/voxelwright/voxelwright/security/advisories/new) and start the title with "Conduct". Only the maintainer can read it. Say what happened, where, when and who was involved, with links where you have them.

The maintainer will reply, keep the reporter's identity private, and act following the Covenant's [enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines): a correction, a warning, a temporary ban or a permanent ban.
