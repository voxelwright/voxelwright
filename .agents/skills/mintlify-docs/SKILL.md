# Mintlify docs

The site root is `guide/`. Keep the page paths in `guide/docs.json` relative to that directory, without file extensions. Place each new guide in the group where a reader would look for it.

Check the configuration and navigation locally before requesting a deployment. Public deployment requires owner approval.
