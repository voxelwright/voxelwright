# Documentation maintenance

Update README commands and the affected pages in `guide/` in the same pull request as their source. Read the [documentation gate](../../../guide/documentation.md) for bindings, generated pages and local checks. Use the [project map](../../../guide/project.md) to find component guides.

Check the changed commands and describe the result in the pull request. Keep private evidence and personal information outside the guide.
