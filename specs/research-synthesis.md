- Product: stable assistant relationships, authorized private/shared context, completed responsibilities, capacity pool, connections and workshop. First proof focuses on the existing engineer relationship; no real family data imported.

- OpenClaw: existing working execution environment; Gateway is one trust domain. Reuse with explicit adapter and restricted single-owner entry, not a claim of household isolation.
- DSH: composition/multiplayer worth evaluating; separate LiveShare server and non-passive view role complicate permissions. No adoption benchmark completed.
- GasCity: durable attempts, uncertain delivery, reconciliation concepts useful. Source contracts and historical reports are not reproduced runtime outcomes.
- NixOS: candidate generation-managed build/recovery experiment; no host migration for dogfood. Software rollback does not restore data or undo external effects.
